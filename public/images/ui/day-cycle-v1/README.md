## Native surfaces and shared art

Fourteen editable SVGs are exact reuse of the approved Feeding Station polish family, generated by `scripts/build-feeding-polish-assets.py`. Copied here as a versioned day-cycle kit so subsequent refinement does not silently alter the Feeding Station.

Three new native symbols extend that family: `timer.svg`, `check.svg` and `warning.svg`. They use the same antique-gold highlights, ivory marks and navy/emerald/amber state colors; labels must always accompany their meaning. This gives the kit seventeen native surfaces/symbols in total.

Retain `fill` for surface centers, readable ivory text and explicit Tinos regular 400/bold 700 from `forge-slate-v2/fonts`. Reuse existing painted hearts, Energy, food, nursery and navigation symbols instead of inventing replacements. Runtime controls remain native semantic buttons, checkboxes and selectors; raster images are decoration.

The downloadable `docs/production-kits/day-cycle-v1.zip` includes both WOFF font weights and their OFL license alongside the surfaces, illustrations and manifest. The in-project manifest keeps the existing shared font URLs.

Creature slots must consume registered `portraitPath` bust art, including the current Nyla and Equine canonical portraits. Never regenerate creatures or use full-body/profile art for these menus. The concept reference uses Mira's existing bust; any unillustrated resident can use a neutral paw crest in proposals, never a new invented character.

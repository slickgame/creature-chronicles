# Complete Record C — Open Ledger

Approved source: source/approved-options.png, C Open Ledger. This is a live saved-record interface shared by the immediate result and historical Ledger.

## Assets
- open-ledger.webp: independently generated transparent leather-bound ledger, blank header and two-page paper spread. Original PNG and exact generation prompt under source/. Trimmed with sharp threshold8, width1600, WebP quality96, alpha preserved.
- sprig.svg: exact existing editable scenic-folio botanical symbol, reused in the heading and left margin.
- Existing engraved cream/emerald controls from breeding-result-journal-b, licensed local Tinos fonts and Pair Options ranch environment reused unchanged. Phones reuse the approved thin single-page folio from saved-scenes-folio-a. No character or scene art was regenerated.

## Native content
All names, outcomes, days, Energy, XP, levels, innate grade changes and stat increases come from the immutable saved attempt. The concept's sample values are never hardcoded. Historical Hearts without a captured pre/post snapshot display the exact saved cost, with hover/focus/tap help explaining the missing snapshot.

Three primary tabs: Summary, Costs & Growth, Next Actions. The growth overview has both parent cards, cost table and familiarity/Breeder XP. Previous/Next appears for meaningful recorded growth events; short screens also use Resources / XP & familiarity focus views. Growth pages show saved deltas rather than inventing unrecorded before-stat values. Full process/flavor, blocker, progression/talent and offspring comparison records remain reachable in grouped read-only dialogs. No reducer, cost, odds or save schema change.

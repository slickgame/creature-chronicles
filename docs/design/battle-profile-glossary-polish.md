# Battle Profile and Glossary Polish

## Goals

- Use more of the available vertical battlefield space at desktop widths.
- Increase creature profile size without allowing neighboring lanes to overlap.
- Raise profile artwork slightly while preserving grounded nameplates and selection rings.
- Explain battle statuses and gameplay terms using the exact live combat rules.
- Keep definitions available through both hover/focus tooltips and visible move-detail references for touch users.

## Scope

This pass changes presentation and combat-language help only. It does not change battle calculations, status values, AI, targeting, rewards, progression, or save data.

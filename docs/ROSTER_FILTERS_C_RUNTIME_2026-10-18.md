# Filters & Sort C

The user selected C and explicitly requested assets, fonts, sizing, spacing and layout that reproduce its visual direction. RosterFiltersC replaces the old parchment window with a portaled navy/gold side drawer. Desktop keeps the roster visible at left; phone uses a full-width compact window. Condition, Details and Sort are mutually exclusive accordion panels with fixed count and footer. The asset map and reproducible native art generator are in `public/images/ui/roster-filters-c/README.md`.

All existing search/filter options and ten sort modes are retained, except the already removed binary Sex control. The selected profile and tab remain unchanged. Local draft values drive the live match count. Show creatures applies filters/sort in UI state; Cancel, close and Escape discard the draft. Clear filters resets the draft only, preserving the selected sort. Family changes reset Variant. Empty results are allowed. No filtering action saves or modifies creatures, equipment, resources or breeding mechanics.

Sort direction uses A to Z / Z to A for names and variants, Oldest / Newest first for acquisition order, and Lowest / Highest first for numeric and ranked fields. Ranch totals remain available in Sort. The new title is Filters & Sort, replacing Roster Filters & Sort; existing picker browser coverage is updated accordingly.

The comparison board and baseline screenshots remain under `public/images/ui/roster-filters-review` and `docs/validation/roster-filters-before-*`. Actual results and tests will be recorded separately. PR21 remains draft and unmerged.

Validation: production build passed; 66 dedicated filter checks and 47 picker regression checks passed (113 total). Six viewports cover desktop, phone, short landscape and mobile-keyboard height. Each accordion section is checked for visible fields, containment and loaded assets. Interaction checks cover draft counts, Apply/Cancel/Escape, clear cancellation, favorite filtering, family/variant reset, zero matches, sort direction wording and no save writes.

# Equipment removal entry-point correction — October 17, 2026

The prior B integration updated Improve Equipment only. EquipmentGallery, which serves Menu → Inventory and creature-card Equipment tabs, still mounted the old paged-book confirmation and text receipt. The active Outfitter Manage Equipment path also had its own old plain dialog. These were real missing entry-point integrations.

EquipmentGallery and BattleOutfitterBench now invoke EquipmentActionFlow for both equip and remove. It renders the existing approved EquipmentAssignment / EquipmentResultWindow components and produces receipts from actual persisted saves. Gallery filters, selected copy, recipient and source returns remain in their parent screens. Purchase, manual use, upgrades and non-equipment inventory flows retain their existing behavior. Unused historical screen implementations are not active routes and were not redesigned.

The shared detached quote selects and validates the exact requested copy, preserves training/gauntlet restrictions, checks that removal targets the current wearer, and fingerprints the reviewed copy plus actual battle/set changes. Confirmation requotes against current save state and rejects changes. A synchronous busy guard allows one save; review and receipt have distinct React keys so each starts minimized and the receipt's Continue click-through guard is fresh. Cancellations never save. No equipment currency charge, balance tuning, RNG or save schema change. Legitimate first-time goal rewards remain reported separately in the receipt.

Validation: production Next build/TypeScript; scoped lint zero errors; all 357 regression tests pass. Added tests cover exact duplicate-copy selection, read-only quotes, owner/availability/training rejection and stale upgraded-copy fingerprints. Actual production-browser QA enters through Inventory, creature Equipment and Town → Battle Outfitter. Each route checks the B removal review at 1440×900, 390×844, 360×740 and 844×390, expanded stats and persistent lost-bonus warnings, cancellation, rapid removal/equip confirmations, preserved copy IDs/levels/rolls/rarity, no Gold charge (goal awards may increase the balance) and reload persistence. Approved B's previous seven-viewport visual verification remains applicable; this patch changes routing and transaction review reuse.

Screenshots use an isolated synthetic established save with six-stat removal. Missing unrelated legacy art in the sparse checkout uses a QA-only canonical workshop fallback.

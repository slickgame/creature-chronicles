## Selected B refinements

- Status artwork and contextual badges replace the healthy emblem and Ready text when appropriate. Current management states include Training, injury severity, Recovering, Pregnant, Hurt, Exhausted, Tired and recent breeding. Keep health separate from availability: a healthy creature can still be tired or occupied. Show exact current state and applicable details, never assert Ready simply because no injury exists.
- Create distinct Healthy, Hurt, Injured, Tired, Exhausted, Recovering, Training and Pregnant icon treatments. Sick artwork is reserved for the deferred sickness system; it must not add illness, dirtiness or forced-rest mechanics or appear on a currently healthy save. Recent breeding retains the existing label and should not be described as an action block without evidence.
- Up to five hearts may use individual full/empty hearts. Above five, use one gold heart, exact current/max text and a normalized gold progress bar. Do not cap the display at five or imply that each decorative heart represents several actual hearts. Use actual values and preserve partial fills if supported.
- When unlocked, show an open padlock and action label **Lock creature**. When locked, show a closed padlock and action label **Unlock creature**. The icon represents the current state; the label names the next action. Supporting copy explains current protection. Preserve the existing toggle and removal protections.
- Keep B's split composition and existing action callbacks. Release and Donate retain their review/confirmation flow. On phone use focused Care / Management views with the existing section dropdown and footer; no redundant pagination.

The refined main concept deliberately uses illustrative Tired/18-of-40 Energy and 16-of-16 Hearts to exercise non-Ready and high-heart presentation. A separate 12-of-16 example demonstrates partial heart fill. These are not mutations to Mira's actual save.

## Service mission status addition

The user requested matching artwork and a contextual text box for creatures temporarily away on a service mission, analogous to Training. Add a gold compass and sealed ivory commission icon, muted blue **On service mission** badge and **Temporarily unavailable.** supporting text. Use actual mission title/return information only when provided by saved assignment data; never invent a countdown. This state represents availability, not illness or injury.

Current `src/data/guild.ts` service submission deducts Energy, grants XP/Affection, records submission and completes the contract immediately. `GuildContract` currently has no departure/return assignment interval, and creature management does not expose a service-away state. The artwork is prepared for a future timed-service flow, not evidence that such a flow is already implemented. Do not infer away status from accepted or completed service contracts, and do not block current creatures simply because service artwork exists.

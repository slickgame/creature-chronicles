# Creature Chronicles Visual Masters

This directory is the canonical archive for approved full-sheet visual references. Master sheets are preserved unchanged and are not used directly by gameplay code.

## Approved visual direction

- Ornate black-and-gold frames
- Dark vignette backgrounds
- Warm painterly 3D rendering
- Luminous magical effects
- Expressive furry-coded subjects where characters appear
- Exact five-column by four-row icon-sheet structure
- Gold serif numbering and labels on reference sheets

## Production policy

1. Never overwrite an approved master with a later experiment.
2. New revisions receive a new filename until explicitly approved.
3. Individual gameplay icons belong under `public/assets/icons/`, not in this folder.
4. Production icons should be square, consistently sized, lowercase, and hyphenated.
5. The printed labels and numbering belong only to the visual-master sheets.
6. Isolated production icons should eventually use transparent backgrounds where practical.
